# TalentUm School World

Статический многостраничный сайт, готовый для GitHub Pages.

## Публикация
1. Загрузите все файлы из этой папки в корень репозитория GitHub.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: / (root).
5. Сохраните и дождитесь публикации.

## Что позже заменить
- `teachers.html` — реальные педагоги.
- `reviews.html` — отзывы родителей.
- `license.html` — лицензия.
- `attestation.html` — подробный документ об аттестации и прикреплении.
- `contacts.html` — реальные контакты.
- цены 7–11 классов — после получения данных.
