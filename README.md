# TalentUm School World — GitHub Pages

Готовая версия сайта. Главная визуально повторяет утверждённый 3D-макет и содержит кликабельные области, видео-блок и кнопки Telegram / Instagram / WhatsApp.

## Загрузка на GitHub
Загрузите все файлы из этой папки в корень репозитория, чтобы `index.html`, `home-design.png`, `school-preview.mp4` и остальные `.html` лежали на одном уровне.

## Социальные ссылки
В `index.html` найдите строку `const socialLinks={...}` и вставьте ссылки TalentUm в кавычки. Пока ссылки пустые, кнопки показывают подсказку.

## Видео
`school-preview.mp4` — временный демонстрационный ролик из текущего визуала. Когда будут реальные нарезки/анимации, замените файл с тем же именем — код менять не нужно.
